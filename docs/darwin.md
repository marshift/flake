# Manual settings for darwin

Some stuff cannot be configured by nix-darwin, so the following needs to be done manually

## Apple ID

### iCloud

- Press see all on "Saved to iCloud" and turn literally everything off
- Turn on Advanced Data Protection (if possible)
- Data access on iCloud.com: off

## Notifications

### Show notifications

When display is sleeping: off
When screen is locked: off
When mirroring or sharing the display: off (screensharing)

## Touch ID

- Use Touch ID to unlock your Mac: off

## Spotlight

- Help Apple improve Search: off
- Results from clipboard: off

## General > Software Update

### Automatic Updates

- Download new updates when available: off
- Install macOS Updates: off
- Install System Data files and Security Updates: off

## Privacy & Security

- Sensitive Content Warning: off

### Analytics and Improvements

DESTROY!

### Apple Intelligence Report

- Report duration: off 

### Accessories

- Allow accessories to connect: always ask

## Login

- Require password after screensaver begins or display is turned off: immediately
